# 测测你的灵魂对应哪位中国历史人物

解压 ZIP 后，双击文件夹里的 `index.html`。网页、题库、计分和分享图均在浏览器内运行。请把 HTML、CSS、JavaScript 和 `assets` 文件夹保留在原来的相对位置。

## 题库与计分

40 道题分为日常习惯、处事方式、社交模式、情绪反应和兴趣偏好五组。每道题有四个选项，每个选项给一种倾向加 1 分。谋略、主导、通达、守义、探索、笃行、自持和敏察在每组中各有四次可选机会。

每位人物有一项主要倾向和两项辅助倾向，权重依次为 6、2、1。将作答频次乘以权重相加，综合得分最高的人物即为匹配结果。同分时优先匹配主要倾向出现更多的人物，随后从最后一道题往前寻找能区分两者的作答。结果页的「次」表示相应倾向在 40 次作答中的出现次数。

## 文件

- `index.html` 包含首页、答题和结果的页面结构。
- `styles.css` 管理排版、进度条、过渡动画和响应式布局。
- `quiz-data.js` 包含问题、选项映射和人物文案。
- `scoring.js` 负责校验答案并计算匹配结果。
- `app.js` 处理交互并生成 1080 × 1440 PNG 分享图。
- `assets/ink-landscape.js` 内嵌首页和分享图使用的原创插画。插画由 ImageGen 生成，提示取意宋风山水、宣纸纹理、朱砂日轮、薄雾、松崖和背身远眺的旅人。旅人为虚构形象。
